# Technical and Business Metadata

## Metadata

- Data about data
- Metadata includes details about data structure, format, origin, quality and meaning.

- Technical metadata focuses on the detailed aspects of data, like file formats, structure, source and lineage. 
- Business metadata includes the meaning of the data, associated business rules, and information about data ownership and relationships.
	- It provides the necessary context to understand the significance and relevance of data in the context and business objectives. 

- **Technical metadata focuses in details** 
- **Business metadata provides the business context and meaning**
