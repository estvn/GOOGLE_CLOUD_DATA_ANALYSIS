# Introduction to Data Catalogs

# Data Catalog

- A centralized inventory of an organization's data assets.

### Data catalog components

- Structured data
- Unstructured data
- Reports
- Dashboards and visualizations
- Automations and machine learning models

### Key elements of data catalog

- Metadata
- Data lineage information
- Data governance

### Benefits of a data catalog

- Enhance data understanding
- Quickly locate and access important data assets
- Decrease time spent on data preparation
- Enforce governance practices
- Create a wonderful culture of innovation
