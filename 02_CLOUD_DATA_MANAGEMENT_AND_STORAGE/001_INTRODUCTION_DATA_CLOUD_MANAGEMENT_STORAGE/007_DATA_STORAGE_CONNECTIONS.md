# Cloud Data Storage

- A solution that enables organizations to keep, access, and maintain digital data in off-site, cloud-based servers
- They don't need to own or manage
- Data can include files, business data, videos, images, and tons more. 
- Data analysts focus on input and output data.

## Input data

- Any information that a user sends to a computer

## Output data

- Any information that a computer sends to a user
- Data storage systems can be used to store both input and output data

# Common Storage Systems

- Systems of record
- Transactional databases
- Cloud storage

## System of Record

- A data-storage system that serves as the source of truth for an organization's data related to processes or systems

## Transactional Databases

- A data-storage system that stores each transaction, or interaction, and their fields as individual rows. 
- Are common in e-commerce, online banking, and other business that may record customer transactions.
- A transactional database can also be one of your systems of record.

## Cloud Data Storage

- A solution that enables organizations to keep, access, and maintain digital data on off-site, cloud based servers
- Scalable when you need to increase or decrease capacity

### Data connection 

- A link formed between a data source and another tool in order to access the data source from the tool.
- The tools to analyze data or manage data provides an intern tool to connect to a data source
