# Structured, Unstructured and Semi-structured Data

## Structured Data

- Data organized in a certain format like rows and columns
- Structured data is easily stored in traditional databases like a SQL database.
- Primary key and foreign key

## Unstructured Data

- Data that is not organized in any easily identifiable way
- Cloud-based data-lakes are well-suited to unstructured data.
- It's even more challenging to process and interpret
- They store data are documents or files
- Can have any number of fields in nested data structures, or no structure whatsoever.
- **This allow a data analyst to quickly store, search, and analyze data as needed, no matter the data format**
- It's also easy to modify data without impacting the application

## Semi-structured data

- Data that has some structure, but is not as precisely organized as structured data.
- It's more flexible than structured data, which makes it great for storing data that might not fit into a traditional table or spreadsheet format.
- email is an example, the common fields are structured, the body of the main is unstructured.
