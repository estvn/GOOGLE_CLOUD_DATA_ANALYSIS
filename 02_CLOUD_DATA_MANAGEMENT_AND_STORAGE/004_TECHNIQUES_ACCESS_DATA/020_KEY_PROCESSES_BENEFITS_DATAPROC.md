# Key Processes and Benefits of Dataproc

# Dataproc

- Managed Spark and Hadoop service that integrates open source data tools for batch processing, querying, streaming, and machine learning.
- With Dataproc, users can create clusters quickly, manage then easily, and save money by turning off cluster when they're not needed 

- Using Hadoop and Spark clusters, the data analyst can significantly reduce the manual effort required, process data efficiently, and mitigate potential errors.

## Key Dataproc Processes

- Batch processing
- Querying
- Streaming
- Machine Learning

# Hadoop

- A framework that distributes the processing of data across clusters of computers.
