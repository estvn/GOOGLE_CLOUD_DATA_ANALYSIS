# Steps and Model for Accessing Data with Machine Learning

# Machine Learning 

- The use and development of algorithms and statistical models to each computer system to analyze and discover patterns in data.

Retrieving datasets:

- Choose the appropriate cloud service provider
- Set up the necessary credentials and permissions
- Establish connections to the data resources

Code Interfaces:

- Login credentials
- APIs
- SDKs

## Application Programming Interface

- A protocol that enables one application to interact with another application

## Software Development Kit

- A set of software-building tools that includes groups of code libraries

## Classification

- The process of grouping items into a predefined category based on common characteristics

## Clustering Model

- Grouping data points that are similar to each other in some way

## Linear Regression

- A technique that estimates the linear relationship between a continuous dependent variable and one or more independent variables. 

## Ranking

- The process of using characteristics to order items by likelihood.
