# Methods for Defining BigQuery Table Schemas

# Database Schema 

- A way of describing how an entire database is organized, including its tables and their relationships.

# Table Schema

- A way of describing how each individual table within a database is organized, such as its columns and data types.

There are three primary ways that table schemas are created:

1. Load the data into a table from the Google Cloud console
2. Use schema auto detection
3. Use a JSON schema file
