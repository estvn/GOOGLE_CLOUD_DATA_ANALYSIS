# Overview of Google Colab

- Google colab is a hosted-version of Jupyter Notebook that allows users to write and execute python in a browser, with no configuration required. 

### Jupyter Notebook programming languages:

- Python 
- Java
- R
- Julia
- Mathlab
- Octave
- Scheme
- Processing 
- Scala
- etc

### Jupyter Notebook uses

- Data visualization
- Bash scripts
- Markdowns
- Mathematical and scientific notations

> [!NOTE]
> Colab users can combine executable code and rich text in one document, and images, HTML, LaTex, and more

- Data scientists use Colab and python libraries to see data graphs and visualizations
- Machine learning programmers also use Colab for their data work

# Benefits of Colab Notebooks 

- Uses Graphical processing units (GPU) and tensor processing units (TPU) for 12 hours with no costs
- Notebook sharing
- Install libraries
- Pre-installed libraries
- Github integration
- Multiple data sources
- Automatic version control
- **Colab resources are not guaranteed and not unlimited and the usage limits may vary**

- All its content can be shared
- Users can omit code cell output from being saved or shared
