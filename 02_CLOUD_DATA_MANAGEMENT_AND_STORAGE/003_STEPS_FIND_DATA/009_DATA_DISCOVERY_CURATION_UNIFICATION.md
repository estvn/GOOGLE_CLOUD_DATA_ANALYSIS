# Data Discovery Curation and Unification

# Data Discovery 

- The process of finding and understanding data assets within a dataset or data ecosystem, and identifying relevant patterns ad relationships
# Data Curation

- The process of selecting and organizing data to ensure it's useful and of high quality
- Curating the data creates a solid foundation for analysis and decision-making
# Data Unification

- The process of integrating data from diverse source to create a consolidated view.
- Data unification brings together disparate data sources, harmonizes their structures, and enables holistic analysis.
## Cloud

- Cloud solutions allows seamless access to data discovery, curation and unification tools from anywhere in any time.
