# Overview of Version Control and Views

## Versioning

- The process of creating a unique way of referring to data

### Benefits of versioning

- Support quality control
- Revert to a previous version
- Support compliance concerns
- Find where edits are incorrect

## Hold

- Hold is a policy placed on a dataset that prevents its deletion or prevents deletion capabilities for certain accounts.
- Sometimes, dataset will have an organization-wide hold, meaning no one can delete it.

### Benefits of holds

- Prevent accidental deletion
- Preserve data indefinitely
- Determine and define each user's responsibility for datasets

# Why use Versioning and Hold Data

- Mitigate security concerns about sensitive information
- Manage storage costs
