# Data Lifecycle

- The sequence of stages that data experiences, which include plan, capture, manage, analyze, archive, and destroy.

## 1. Plan

- The plan stage begins before you start any analysis
- Business question
- Objective
- Data types - team decides what data types to collect
- Data management processes 
- Who is responsible for each stage
- Outcomes/resultados
- How to measure success

## 2. Capture

- Data is collected
- Gaps are identified
- Iteration occurs

### 2.1 Process captured data

- Clean 
- Transform
- Compress
- Encrypt

## 3. Manage 

- Data maintenance
- Safe and secure data storage
- Ongoing process / proceso continuo

## 4. Analyze 

- Answer the business questions
- Meet the business objective 

## 5. Archive

- Store data for later use

## 6. Destroy

- When data is no longer useful
- Ensure that sensitive data cannot be stolen
- Support privacy protection guidelines
- Meet other compliance requirements and regulations - Like GDPR
