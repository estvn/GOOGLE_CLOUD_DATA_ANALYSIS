# Process of migrating to a cloud platform

- Steps to follow
- Cloud data migration strategies
- Factors to consider

## Steps to follow

1. **Think about key factors** 
	- choose the right cloud environment for your organization
	- Think about how much data will be migrated to the cloud
	- How much downtime your organization can deal with during the operation
	
2. **Choose your migration strategy**
	- rehosting, repurchase, replatforming, refactoring, retiring etc.
	- **rehosting or lift-and-shift** -
		- A cloud strategy that involves moving a entire on-premises system to the cloud.
	 - **replatforming** 
		- A cloud migration strategy that involves making small changes to the on-premise system once it's migrated to the cloud
	- **repurchasing** 
		- A cloud migration strategy that involves moving applications to a new, cloud-service cloud platform, usually a **software-as-a-service** (SaaS).
		- Maybe require the retraining of the team for new experiences
	 - **Refactoring** 
		- A cloud migration strategy that involves building all new applications from scratch and discarding old applications
		- Useful when the organization needs new features, like serverless computing
	- **retiring** - Applications that are no longer useful are turned off. 
	
3. **Choose your migration partner**
	- Choose the cloud that offers the right infrastructure for your particular business. 
	- **Google Cloud Adoption Framework**
		- Helps to the costumers to assess the right cloud technologies to use

## Migration Path Phases

- Assess/evaluar
- Plan
- Deploy
- Optimize

- In this way we start to improve accesibility, scalability, cost-savings, security and efficiency.
- Cloud migration requires careful planning.
