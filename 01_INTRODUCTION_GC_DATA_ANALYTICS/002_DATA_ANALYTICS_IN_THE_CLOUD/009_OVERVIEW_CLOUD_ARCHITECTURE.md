# Overview Of Cloud Architecture

Cloud architecture components:

- Frontend platform
- Backend platform
- Cloud-based delivery model
- Network

## Frontend Platform

- The component of cloud architecture that users interact with, including the screen design, apps, and home or work internet networks.
- Allow users to connect and use cloud computing services.

## Backend Platform

- The components of cloud architecture that make up the cloud, including computing resources, storage, security mechanisms, and management.
- Are accessed by the frontend, then the backend completes the tasks.

Backend platform:

- Application - A mobile app that communicates user with the backend
- Service - Heart of the cloud architecture
- Runtime cloud - Provides space for all cloud services to perform efficiently
- Storage - Cloud service providers keep the data to run systems
- Infrastructure - Hardware of the server, CPU, GPU, etc.
- Security
