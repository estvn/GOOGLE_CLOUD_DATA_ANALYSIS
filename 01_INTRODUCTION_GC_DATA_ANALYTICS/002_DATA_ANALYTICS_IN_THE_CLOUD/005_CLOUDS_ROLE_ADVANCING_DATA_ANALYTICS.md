## Cloud Data Management

- Data integration

## Data Integration

- The process of combining data from different sources into a single, usable data source.
- This integration happen through an ETL or ELT process.
- ETL and ELT are cloud-based approaches that use the the power of cloud datawarehouses like **BigQuery** to transform data.

- ETL transforms the data before to load into a datawarehouse.
- ELT transforms it after.
- But either way, it's ready for analysis

## Data Ingestion

- The process of obtaining, importing, and processing data for later use or storage. 
- The information is obtained from various resources and processed through stream and batch ingestion.
