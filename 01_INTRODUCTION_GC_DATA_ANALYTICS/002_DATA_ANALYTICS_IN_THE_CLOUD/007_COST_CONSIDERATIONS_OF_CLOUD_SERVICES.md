# Cost Considerations Of Cloud Services

key features that affecting cloud costs:

- Resource provisioning
- Storage
- Running queries

# Resource Provisioning

- The process of a user selecting appropriate software and hardware resources and the cloud service provider setting them up and managing them while in use.

Resource provisioning process occurs through one of three delivery models:

1. Advanced provisioning
2. Dynamic provisioning
3. Self-provisioning

## Advanced provisioning

- A cloud delivery model in which the user signs a formal agreement with the cloud service provider and either pays a set price or is billed monthly 

## Dynamic provisioning

- A cloud delivery model in which resources are adjusted based on the user's changing needs and they are only charged for what they use.
- Can scale up or down based on usage demands.

## Self-provisioning

- A cloud delivery model in which the user purchases resources from the cloud provider through a website or online portal, then the resources are quickly made available for the user.

Payment can be arranged with one of three rates:

1. Fixed
2. Pay-as-you-go
3. Instant purchase

# Storage

- Data storage
- Data processing
- Network use

## Data storage 

- The amount of data kept in storage spaces called "buckets".

## Data processing

- Raw data is cleaned, organized, and changed into a format for easy analysis. 

## Network use

- The amount of data that is read or moved between storage buckets.

# Running Queries

### BigQuery pricing models

- On-demand pricing - Based the amount of data in bytes, that each query processes.
- Capacity pricing - Based on the computing power to run queries over the time.
