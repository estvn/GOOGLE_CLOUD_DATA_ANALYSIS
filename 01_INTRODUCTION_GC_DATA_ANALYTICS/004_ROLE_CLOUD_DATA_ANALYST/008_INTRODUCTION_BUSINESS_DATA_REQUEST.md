# Introduction to Business Data Request

# Business Data Request

- Any business question that can be answered with data
- Whether the request involves data that already exists or new data
- Data request can be simple or complex. Some can be responded by a single data analyst, other will require a team of data analysts to work together to generate a large report. 

Elements of a data request:

- Internal
- External
- Answers to a data-related question
- Data report, extract, or dashboard
- Information or structure specifics

## Working on a Data Request

- Overaching goal
- What's being measured
- What data is needed and how much
- Outliers
- Trends
- Summary report
