# Data Access Management for Secure Data

- The process of implementing features, including password protection, user permissions, and encryption to protect data and related processes. 
- In the context of the cloud, it includes the creation of individual user roles or user groups.
- And the access of each role is pre-defined by the administrator.

- The act of assign this access is called **identity access management (IAM)**.

# Identify Access Management - IAM

- The process of assigning certain individual roles or groups with access to particular resources. 
- Some key resources may include software hosted in the cloud, databases, datasets or entire datawarehouses. 
- **The level of the access is determined by the role of the user**

Identity access management:

- Principal - The account or accounts that can access a resource
- Role - The collection of permissions that an account can access to
- Policy - The collection of roles that are attached to a principal

# Types of Access

- Universal access: access that anyone needs
- Access by roles: access for each role assigned to a project
- Access by environment: access determined by where the user logs in

# Best Practices in Data Management

- Audit data access and monitor user tasks
- Put additional permissions on remote access
- Verify and stop unusual activities
- Add two-factor authentication
