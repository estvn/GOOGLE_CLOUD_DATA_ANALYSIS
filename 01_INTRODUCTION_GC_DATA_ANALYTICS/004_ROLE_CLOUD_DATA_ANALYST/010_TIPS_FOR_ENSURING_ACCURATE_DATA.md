# Tips for Ensuring Accurate Data

## Business Data Request

- A business question that you can answer with data

## Data Cleaning Phase - Data Wrangling

- Correct or eliminate inaccurate or repeat records from the data set
- Define specific segments
- Break down the dataset into smaller sections

## Data Validation and Integration Phase

- Check for outliers
- Integrate multiple data sources
- Check summary statistics
- Compare to previous work
