# Clear Documentation Benefits the Whole Team 

## Data Documentation 

- A written guide to the data contained in a dataset, how it was collected, and how it's organized

Data documentation may include:

- Purpose
- Procedure
- Date and time data was collected
- Structure of the dataset
- Notes about data validation and quality assurance

### Data documentation 

- README files
- Data dictionary
- Codebook
- Lab notebook
- Spreadsheet

## Team's data Playbook 

- How to request data access
- How to grant data access to others
- Where your team stores tables in BigQuery
- How to carry out common tasks
