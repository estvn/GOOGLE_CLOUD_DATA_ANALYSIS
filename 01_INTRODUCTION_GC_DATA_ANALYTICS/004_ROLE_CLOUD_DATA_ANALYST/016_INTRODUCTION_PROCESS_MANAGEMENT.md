# Introduction to Process Management

## Typical Data Analyst Workflow

- Using a data request central system
- Checking in code
- Keeping an internal record

## Documentation 

- A process for preserving all of the details and conversations about each request in one place

## Collaboration

- Members of the data analytics team visit the central system to review data requests, including queries and data delivery methods. 

## Historical Methods

- Past data or information that's been stored and can be accessed or retrieved when needed.
- This supports collaboration and helps refresh your own memory

## Check-in

- Upload code to a main repository so others can access it and review it.

Check-in benefits:

- More effective collaboration
- Centralized repository
- Improve code quality
- Track code easily
- Easier way to revert code
- Revision history
- Easier to locate code
