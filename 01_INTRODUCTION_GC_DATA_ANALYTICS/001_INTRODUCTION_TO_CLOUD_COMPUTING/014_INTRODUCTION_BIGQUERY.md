# Introduction to BigQuery

## BigQuery 

- A data warehouse on Google Cloud used to query data, filter large datasets, aggregate results, and perform complex operations. 
- BigQuery works with SQL

- BigQuery will tell you the number of bytes the query will run so you can estimate the cost before querying the database.
- BigQuery allows the scheduled queries, to refresh the data in charts, etc.
- Includes functionalities with ML and AI.
