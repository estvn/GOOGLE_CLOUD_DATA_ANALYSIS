# Cloud Data Warehouses

- A large-scale, data storage solution hosted on remote servers by a cloud service provider.

Advantages of a Cloud data warehouse:

- Fully managed by the cloud provider
- Saves time, money and resources
- More uptime compared to on-premises data warehouses
- Ability to scale and support increased demand of data
- Integration of separated data
- Real time analytics
- Artificial intelligence and machine learning

- Uptime - The time the machine is operational
- Custom reporting and analysis
