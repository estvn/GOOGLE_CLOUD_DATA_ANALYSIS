# Data Center

- A physical building that contains servers, computer systems, and associated components
# Cloud Computing Service Models

## Infrastructure as a Code (IaaC)

- A cloud computing model that offers on-demand access to IT infrastructure services, including hardware, storage, networking, and virtualization tools.
## Platform as a Service (PaaS)

- A cloud computing model that provides hardware and software tools to create an environment for the development of cloud applications, simplifying the application-development process 
- Its all to help users build apps
## Software as a Service (SaaS)

- A cloud computing model that provides users with a licensed subscription to a complete software package.
