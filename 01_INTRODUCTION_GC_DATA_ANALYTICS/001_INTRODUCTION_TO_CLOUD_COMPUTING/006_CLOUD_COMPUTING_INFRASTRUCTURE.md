
# **Cloud computing infrastructure:**

1. Hardware 
2. Storage 
3. Network
4. Virtualization

## Types of hardware include

- Servers
- Processors 
- Memory
- Network
	- Switchers
	- Routers
	- Cables
- Firewalls
- Load balancers
- Cooling systems
- Power supplies

## Data storage in the cloud can occur in three different ways:

1. File - hierarchical data
2. Object - unstructured data with metadata 
3. Block - Multimedia 

## Network 

- Connect to back-end cloud resources
- Uses the already mentioned hardware to connects services with costumers

## Virtualization

- Technology that creates a virtual version of physical infrastructure, like servers, storage and networks.
